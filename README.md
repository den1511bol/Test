# Orbit Brawler

Экшен-выживалка для Android (Kotlin + Jetpack Compose, всё нарисовано кодом, без картинок).
Разработчик: @yfeeeee

## Геймплей
- Вид сверху, управление одним пальцем: води по экрану, герой бежит. Оружие крутится и бьёт само.
- Толпы врагов: гоблины, рыцари, летучие мыши, каждые 90 секунд босс.
- Оружие: топоры (орбита), молоты (медленные, с отбрасыванием), магические снаряды (самонаведение на ближайшего).
- Ящики с оружием дают новое оружие или повышают уровень существующего.
- За кристаллы опыта растёт уровень героя: на выбор три усиления.
- После смерти даётся золото, на него в меню покупаются постоянные улучшения (здоровье, сила, скорость).

## Как собрать APK (с телефона)
1. Залей папку в ветку `brawler` репозитория на GitHub.
2. Вкладка Actions: сборка Build Orbit Brawler APK, около 3-5 минут.
3. Releases -> Orbit Brawler (latest) -> OrbitBrawler.apk.
