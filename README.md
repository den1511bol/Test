# HackSim

Симулятор хакера для Android (нативное приложение, Kotlin + Jetpack Compose).

Разработчик: @yfeeeee

## Самый простой способ: скрипт

На компьютере (Linux, macOS или Windows через WSL) с Java 17+:

```
bash build_apk.sh
```

Скрипт сам скачает Android SDK и Gradle, соберёт проект и положит `HackSim.apk` рядом.
Перекинь файл на телефон и установи.

## Как получить APK без компьютера (GitHub)

1. Создай на GitHub новый репозиторий (можно приватный).
2. Загрузи в него всё содержимое этой папки (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и дождись, пока сборка **Build APK** станет зелёной (около 5 минут).
4. Открой **Releases** -> `HackSim (latest)` -> скачай `HackSim.apk`.
5. Установи на телефон (разреши установку из неизвестных источников).

Если сборка красная, открой лог упавшего шага и пришли его мне, я исправлю.

## Как собрать в Android Studio

Открой папку как проект, дождись синхронизации Gradle и нажми Run (или Build -> Build APK).

## Геймплей

- В мире 50 000 устройств, каждое генерируется по номеру: камеры, роутеры, банкоматы, банки, госсерверы.
- Путь взлома: `scan` -> `connect` -> `probe` -> `bypass` -> `exploit` (при защите 5+) -> `crack` -> `loot`.
- Три мини-игры: обход фаервола (тайминг), эксплойт (память), подбор пароля (логика).
- Трассировка (TRACE): дошла до 100% - штраф и разрыв связи.
- Ловушки (honeypot): иногда их видно через `probe`.
- Ботнет: взломанные устройства приносят пассивный доход, забрать - `collect`.
- Контракты: `mission`, бонус за взлом нужных типов устройств.
- Магазин: `shop`, `buy crack|bypass|stealth`.
- Уровни открывают новые типы целей. Прогресс сохраняется.

Все устройства и сети вымышленные.
