# 👑 Ashen Crown — Пепельная Корона

Мобильная RPG для Android: кампания из 80 этапов в 8 главах, бесконечная башня, арена (PvP-рейтинг), еженедельный мировой босс,
снаряжение 6 редкостей, улучшение и перековка, сундуки с гарантиями, духи-спутники, таланты, задания и достижения.
Клиент собирается в **APK** через GitHub Actions, сервер работает на **Railway** с **PostgreSQL**.

**Разработчик:** @yfeeeee

```
client/   Android-клиент (HTML5 canvas + Capacitor), офлайн-режим, облачные сохранения
server/   Node.js API (без фреймворков, только `pg`), раздаёт и веб-версию игры
shared/   Движок боя, предметы, экономика — один код для клиента и сервера
test/     43 теста (логика, API, клиент на фейковом DOM, интеграция клиент ↔ сервер)
tools/    Симулятор баланса и генератор иконок
```

## 🚀 Деплой сервера на Railway

1. Railway → **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. В проекте: **+ New → Database → Add PostgreSQL**.
3. В сервисе с кодом: **Variables → New Variable → Add Reference** → `DATABASE_URL` из сервиса Postgres.
4. **Settings → Networking → Generate Domain** — получите адрес вида `https://ashen-crown-production.up.railway.app`.
5. Проверьте: `https://<домен>/health` → `{"ok":true,"store":"postgres"}`.

Таблицы создаются автоматически при старте. Проверка здоровья и перезапуск описаны в `railway.json`.
Тот же домен отдаёт **веб-версию игры** (откройте его в браузере телефона — работает и без APK).

Переменные окружения: `DATABASE_URL` (обязательно для прод), `PORT` (Railway задаёт сам), `PGSSL=disable` (подключение к БД без SSL).
Без `DATABASE_URL` сервер стартует с хранилищем в памяти (только для разработки).

## 📱 Сборка APK

APK собирается автоматически GitHub Actions (`.github/workflows/build-apk.yml`) на каждом пуше в `main`
и публикуется в **Releases → «Ashen Crown — последняя сборка»** (файл `AshenCrown.apk`).

1. В репозитории: **Settings → Secrets and variables → Actions → Variables → New repository variable**
   `API_URL` = адрес вашего сервера Railway (без `/` в конце).
2. **Actions → Build Android APK → Run workflow** (или просто сделайте пуш).
3. Скачайте `AshenCrown.apk` из Releases и установите (APK подписан debug-ключом — разрешите установку из неизвестных источников).

> Если `API_URL` не задан, игра запускается в офлайн-режиме, а адрес сервера можно ввести в игре:
> **Ещё → Настройки → Сервер → Проверить / Привязать героя**.

### Локальная сборка
```bash
node client/scripts/prepare.js           # копирует shared/, пишет config.js (если задан API_URL)
cd client && npm install && npx cap add android
node scripts/android-patch.js            # иконки, портретная ориентация, версия
npx cap sync android && cd android && ./gradlew assembleDebug
```
Нужны Node 20+, JDK 17 и Android SDK.

## 🧪 Разработка

```bash
npm install            # pg (нужен только для запуска с PostgreSQL)
npm test               # 43 теста
npm run balance        # симуляция баланса по классам и этапам
npm start              # сервер на :3000, веб-версия на http://localhost:3000
python3 tools/make_icons.py   # перегенерировать иконки
```

## 🎮 Геймплей

- **Классы:** Воин, Маг, Разбойник — по 6 навыков (открываются на уровнях 1/4/10/18/28/40), статусы: горение, яд, кровотечение, оглушение и др.
- **Бой:** пошагово по шкале скорости; ручной выбор навыков и цели, авто-режим, ускорение ×1/×2/×3, зелья.
- **Снаряжение:** 5 слотов, 6 редкостей, аффиксы, перки легендарок/мификов (возрождение, шипы, жажда крови…), улучшение до +15, перековка, разборка.
- **Сундуки:** железный/золотой/духов; гарантия эпика каждые 10 и легендарки каждые 40 золотых сундуков.
- **Арена:** бои против героев других игроков (и ботов) симулирует сервер по сохранённому снаряжению; рейтинг Эло, 5 боёв в день.
- **Мировой босс:** еженедельный общий босс, 12 ходов на попытку, 3 попытки в день, рейтинг по урону.
- **Отдых:** награда копится до 12 часов, пока вы не в игре.

## 🔐 Об античите

Сервер проверяет формат сохранений, лимиты и скорость роста уровней/этапов/самоцветов; арена и босс симулируются на сервере.
Это лёгкая защита для кооперативной игры, а не полноценный античит: клиент остаётся источником прогресса кампании.
