# ⛏ Pixel Miners

Мультиплеерная пиксельная кликер / идл-игра (PWA).
**Developer: [@yfeeeee](https://t.me/yfeeeee)**

## Что внутри

- Тапай по самородку, покупай кирки и шахтёров (доход идёт и в оффлайне до 8 часов)
- **Мировой босс** — все игроки бьют одного босса в реальном времени, награда всем, MVP получает ×2
- **Рейтинг** игроков, **общий чат**, счётчик онлайна
- **Перерождение** за кристаллы (+10% к доходу навсегда)
- Достижения, пиксель-арт графика (рисуется кодом, без файлов-картинок)
- Вход **без Telegram**: «Играть как гость» (+ код восстановления) или ник + пароль; гостя можно позже привязать к нику. Установка как приложение (PWA)
- Пароли хранятся только в виде scrypt-хэша, коды восстановления — как sha256; есть защита от подбора пароля
- Сервер авторитарный: монеты считает сервер, лимит тапов защищает от автокликеров
- Данные хранятся в **PostgreSQL** (единственная зависимость — пакет `pg`), без `DATABASE_URL` сервер пишет в JSON-файл (для локальной проверки)

## Деплой на Railway (всё делается с телефона)

1. Залей папку проекта в GitHub-репозиторий (приложение GitHub или github.com в браузере → *Add file → Upload files*).
2. Railway → **New Project → Deploy from GitHub repo** → выбери репозиторий.
3. В сервисе открой **Settings → Networking → Generate Domain** (получишь `https://что-то.up.railway.app`).
4. **База данных (важно!)**: в проекте Railway нажми **New → Database → Add PostgreSQL**.
   Затем в сервисе с игрой: **Variables → New Variable** → имя `DATABASE_URL`, значение `${{Postgres.DATABASE_URL}}`
   (если сервис базы называется иначе, подставь его имя). Сервис перезапустится, таблицы создадутся сами.
   Прогресс игроков, аккаунты и босс хранятся в PostgreSQL и не пропадают при обновлениях.
5. Если раньше данные были в Volume (`db.json`), при первом запуске с PostgreSQL они перенесутся сами.
6. Открой ссылку в браузере телефона → зайди как гость (и сохрани код восстановления!) → установи как приложение
   (Android: меню Chrome → *Установить приложение*; iPhone: *Поделиться → На экран Домой*).

## Android-приложение (APK)

APK собирает GitHub, компьютер не нужен. Приложение — обёртка (Capacitor) над игрой с сервера Railway,
поэтому обновления игры приходят без переустановки.

1. Код из этого репозитория уже содержит workflow `.github/workflows/build-apk.yml`.
2. Сборка запускается сама при пуше в `main` (изменения в `app/`) либо вручную:
   github.com → репозиторий → **Actions → Build Android APK → Run workflow** (можно указать другой адрес сервера).
3. Через 5–10 минут в разделе **Releases** появится файл `PixelMiners.apk`. Скачай его на телефон и установи
   (Android спросит разрешение «Установка из неизвестных источников»).
4. Адрес сервера по умолчанию: `https://test-production-46b1.up.railway.app`.
   Сменить: переменная репозитория `SERVER_URL` (Settings → Secrets and variables → Actions → Variables) или поле при ручном запуске.

APK подписан debug-ключом: для личной установки этого достаточно, для Google Play нужен релизный ключ.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL (Railway: `${{Postgres.DATABASE_URL}}`) |
| `PGSSL=1` | включить SSL, если база внешняя (для публичных адресов Railway включается сам) |
| `DATA_DIR` | только без `DATABASE_URL`: куда писать `db.json` |
| `PORT` | порт (Railway задаёт сам) |

## Локальный запуск

```bash
npm install
node server.js   # http://localhost:3000, без DATABASE_URL данные пишутся в ./data/db.json
```

## Структура

```
server.js            сервер: API, вход (гость/пароль/код), босс, рейтинг, чат (SSE)
public/index.html    интерфейс
public/game.js       клиент и пиксель-арт
public/style.css     стили
public/sw.js         service worker (PWA)
public/manifest.webmanifest
```
