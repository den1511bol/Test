# Обучение слова «Ифи» (И-фи)

Developer: @yfeeeee

Обучение нужно запускать у вас (Google Colab, бесплатный GPU). Из рабочей среды Claude это сделать нельзя:
там нет GPU и доступа к сети. Названия параметров ниже даны по памяти — сверяйтесь с актуальным ноутбуком.

## Шаги

1. Откройте репозиторий https://github.com/dscripka/openWakeWord → раздел про обучение → ссылка на Colab-ноутбук
   автоматического обучения (`automatic_model_training`). Включите GPU: Runtime → Change runtime type.
2. В настройках ноутбука задайте целевую фразу латиницей так, как она звучит. Английские голоса
   синтеза читают русское написание плохо, поэтому пробуйте варианты по очереди и сравнивайте результат:
   - `ee fee`
   - `eefee`
   - `ifi` (читается как «ай-фай», использовать не стоит)
3. Параметры, которые стоит изменить для короткого слова:
   - число синтетических примеров увеличить (например, до 20 000–30 000);
   - целевое число ложных срабатываний в час поставить низким (например, 0.2), даже ценой меньшей чувствительности;
   - модель назвать `wakeword`.
4. Скачайте полученный `.onnx`, переименуйте в `wakeword.onnx`, положите в эту папку (`models/`), сделайте push:
   GitHub Actions пересоберёт APK уже с вашей моделью.

## Настройка после установки

- Начните с порога 0.5. Для короткого слова, скорее всего, придётся поднять до 0.6–0.8.
- В журнале приложения строки «Почти: 0.xx» показывают, насколько близко было срабатывание:
  скажите «Ифи» 10 раз и посмотрите, какие оценки получаются, затем посидите минуту в тишине или с обычным разговором и
  проверьте, нет ли срабатываний.
- Ложная активация почти безвредна: сообщения без вашего «да» не отправляются, а музыка и таймер запускаются
  только по осмысленной команде.

## Если не получится

Запишите 3–5 образцов, как вы зовёте помощника, и пришлите мне: подумаем, как улучшить
(другая фраза, например «Эй, Ифи», или другой движок активации).
