# Слово-активатор

Положите сюда файл `wakeword.onnx` — модель openWakeWord для вашего слова. Сборка (GitHub Actions)
подхватит его автоматически. Пока файла нет, для теста берётся готовая модель «alexa».

Как получить свою модель: ноутбук автообучения openWakeWord
(https://github.com/dscripka/openWakeWord → раздел «Training New Models», Colab «automatic_model_training»).
Слово задаётся текстом; обучение идёт на синтетической речи (возможность добавить свои записи
зависит от версии ноутбука — смотрите его документацию). Для русского слова пишите его транслитом, как оно звучит, и проверяйте
порог в приложении по журналу («Почти: 0.xx»).
